Quant Notebook

You already build systems that ingest data, train models and ship to production. Quantitative finance asks you to do the same thing in the one domain where the data is adversarial, the signal is faint, and every mistake has a price tag. This course is the whole path — markets, math, data, research discipline, portfolios, derivatives, machine learning, execution and live trading — taught the way engineers learn best: a mental model, a picture, and code you can run.

DURATION ~300 h (100 sessions × 1.5 h + labs) UNITS 16 SESSIONS 100 LEVEL Engineer → professional quant
📌 Start here

New here? Read Start here first (15 minutes: tracks, lab setup, how sessions work). Then open Session 1.1 — What Quants Actually Do and work forward — every session builds on the ones before it, and the roadmap shows exactly which.

⚠️ The honest part

No course can make you profitable, and you should distrust anyone who says theirs can. Most people who trade actively lose money; most backtests that look brilliant fail live; most published "factors" shrink after publication. What can be taught is the process professionals use to find an edge, prove it is real, size it, execute it and survive being wrong — and the honesty to walk away when the evidence says so. That is what this course teaches. Nothing here is investment advice.

Map The whole journey

Sixteen units in five phases. Each phase ends with something you can show — a data lake, a strategy report that survives overfitting statistics, a risk-managed portfolio, a live paper-trading system, and a capstone.

The order is deliberate. Markets, data and statistics come first because every later mistake starts there. Research discipline — backtesting, validation and overfitting statistics — comes before factors, strategies and machine learning, because those are exactly the places where untrained researchers fool themselves. Derivatives, rates and microstructure run as their own tracks on top of that foundation.

How How every session works

One hundred sessions, one rhythm: understand it, see it, derive it, run it, test yourself, then use it.

Every session page links its companion lab — a Python notebook you can open in Colab with one click, or run locally from the repository. The labs use a small teaching package, quantnb, and seeded synthetic data by default, so they run anywhere, offline, in minutes, and always give the numbers the page quotes.
